# Production на Layero

Актуальная конфигурация, полный список переменных, результаты аудита хранилища и пошаговый deploy описаны в [`LAYERO_DEPLOY.md`](./LAYERO_DEPLOY.md).

Не запускайте production с JSON-хранилищем для реальных заказов: runtime-диск Layero эфемерен. До приёма заказов требуется миграция данных в постоянную базу и загружаемых изображений в object storage.
